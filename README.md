# plantdoctor
Software code version 1.0
PlantDoctor是一个基于Spring Boot和Apache Dubbo分布式服务架构构建的Web应用，旨在为农户和基层农技人员提供从病虫害识别到防治决策的一站式服务。系统集成多个第三方AI识别接口，支持水稻、小麦、玉米、大豆、苹果、柑橘、葡萄等10类363种病虫草害的识别诊断，并将识别结果与结构化病虫害知识库实时关联，输出危害症状、发病成因及防治方案。

功能特性
多源AI识别集成：通过可插拔的服务集成框架调用多个第三方病虫害识别API，支持10种作物/害虫类型的检测识别

知识增强查询：识别结果自动关联结构化知识库，返回危害症状、发生因素、防治方法等完整信息

分布式服务架构：基于Spring Boot + Apache Dubbo构建，通过Nacos实现服务自动发现与调用

Web端交互界面：服务端模板引擎渲染 + Vue.js驱动，支持PC端和移动端浏览器访问

可插拔扩展：新增识别服务仅需扩展映射配置，无需修改核心业务逻辑

开源可定制：MIT许可证发布，知识库支持自主扩展与更新
